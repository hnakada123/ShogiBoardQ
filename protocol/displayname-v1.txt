# SBQ 表示名の文字の表 v1（実装仕様 3.2節）
#
# 表示名に使える文字（コードポイント）の範囲。両端を含む16進。通信プロセス（Rust）と
# 対局・UI側（C++）は、この表だけで表示名を判定する（Qt・Rust の Unicode の表を使わない）。
# 判定の規則（この表のほかに）:
#   - UTF-8 で 96 バイト以下、1〜32 文字（コードポイント）
#   - 先頭と末尾が空白（U+0020）でない
#   - すべての文字がこの表の範囲にある
#
# 範囲は、結合文字を含まず、NFC で形の変わらない文字だけから選んだ（正規化の表が要らない）。
# 互換漢字（U+F900〜）は単独で別の文字に正規化されるので入れない。かぎ括弧は、知らせの文で
# 名前を囲む記号なので入れない。範囲を変えるときは表の版と募集の version を上げる。
# 範囲は Unicode 15.1 で割り当て済みの文字。

# ASCII の印字できる文字（空白を含む。先頭と末尾の空白は上の規則で断る）
0020..007E
# 、。〃
3001..3003
# 々〆〇
3005..3007
# ひらがな（結合する濁点・半濁点 U+3099・U+309A は入れない）
3041..3096
# ゛゜（結合しない濁点・半濁点）ゝゞ
309B..309E
# カタカナ（・ーヽヾ を含む）
30A1..30FE
# CJK 統合漢字
4E00..9FFF
# 全角の英数字と記号
FF01..FF5E
