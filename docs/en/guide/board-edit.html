Board Editing

Create positions for games and analysis

1 Start Board Editing

Choose Edit → Start Position Edit to enter board editing mode. Use the following controls to create a position.

  • Left-click: Move a piece to another square, or place a piece from a stand onto the board.
  • Right-click: Change a piece. Right-click a piece on the board to promote it or change its side.

When you are done, click End Edit to leave board editing mode. You can then use the position as the starting point for a game or analysis.

Presets and Side to Move

Set up common positions with one click, or change the side to move

2 Standard Starting Position

Choose Edit → Even Game Setup to set up a regular, even game. This is useful for resetting the board while editing.

Standard starting position: the initial setup for a regular game

3 Tsume Shogi Initial Setup

Choose Edit → Tsume Shogi Setup to prepare a puzzle position. All pieces other than those in the attacker's hand are assigned to the defender's hand, making it easier to construct tsume shogi positions.

Tsume shogi initial setup: a starting point for creating puzzles

4 Move All Pieces to Stands

Choose Edit → Return All Pieces to Hand to move every piece on the board to the players' stands. This is useful for building a position from an empty board.

All pieces on stands: create a position from an empty board

5 Change Turn

Choose Edit → Change Turn to switch the side to move between Black and White in the position you have created.

Change Turn: switch the side to move between Black and White
