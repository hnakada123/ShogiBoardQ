Overview

Generate random tsume shogi candidates and verify mates with a USI engine

1 Features

The tsume shogi generator automatically performs the following steps.

  • Generate random candidate tsume shogi positions.
  • Search for mate with a USI engine using go mate, finding positions with the requested solution length.
  • Trim unnecessary pieces from successful positions to produce simplified puzzles.
  • List results in SFEN format for saving to a file or copying to the clipboard.

Generation Settings

Set the parameters in the generator dialog, then start generation

1 Tsume Shogi Generator Dialog

Choose Tools → Tsume Position Generator to open the dialog. You can configure the following settings.

  • Engine Settings: Select and configure the USI engine for mate search.
  • Target Moves: The puzzle's solution length, such as 3 or 5 plies (each player's move counts as one ply).
  • Max Attacking Pieces: Maximum number of attacking pieces on the board and in hand combined.
  • Max Defending Pieces: Maximum number of defending pieces, excluding the king.
  • Placement Range: The range around the king in which attacking pieces are placed, in squares.
  • Search Time per Position: Engine search time for each position.
  • Generation Limit: Maximum number of positions to find.

Generator dialog: set the engine and generation parameters, then click Start

2 How Random Positions Are Generated

Positions are generated automatically as follows.

  • Place White's king on a random square of the 9×9 board.
  • Place attacking pieces around the king, randomly assigning them to the board or the attacker's hand.
  • Place defending pieces around the king.
  • Add all unused pieces to the defender's (White's) hand, preserving all 40 pieces.
  • Verify that the king is not in check in the initial position.

Candidate positions are sent to the USI engine. Only positions with mate in exactly the requested number of plies are accepted.

Results

Discovered tsume shogi positions appear in the results list

1 Results List

When a mate of the requested length is found, unnecessary pieces are trimmed before the position is added to the results. Pieces that can be removed without changing the mating length are automatically eliminated to simplify the puzzle.

The results list offers these actions.

  • Board Button: Open the principal variation window to inspect the mating line.
  • Save to File: Save the results as an SFEN text file.
  • Copy Selected: Copy the selected position's SFEN to the clipboard.
  • Copy All: Copy all positions as SFEN to the clipboard.

Generation results: ten 3-ply mates found after searching 1,400 positions in 00:01:32

2 Remove Unnecessary Pieces

Trimming automatically removes decorative pieces from randomly generated positions: pieces that do not affect the mating solution.

  • Try removing attacking and defending pieces on the board, and pieces in the attacker's hand, one at a time.
  • Keep a removal if the position still has mate in the same number of plies.
  • Move removed pieces to White's hand to preserve all 40 pieces.
  • Recheck after each removal to find any pieces that have become unnecessary.

Inspect the Mating Line

Review generated solutions in the principal variation window

1 Principal variation window

Click Board in the results list to open the principal variation window. Replay the mating line one move at a time with the Go Forward 1 Move and Go Back 1 Move buttons.
