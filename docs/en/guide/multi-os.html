Cross-Platform Development with Qt6

The Qt6 framework enables support for multiple operating systems

1 One Codebase for Multiple Operating Systems

ShogiBoardQ is built with Qt6 and C++17. Qt6's cross-platform capabilities let you build applications for Linux, macOS, and Windows from the same source code.

2 Consistent Interface Across Platforms

ShogiBoardQ uses Qt6's Fusion widget style to provide a consistent interface across platforms.

  • Linux: supports desktop environments such as KDE Plasma and GNOME
  • macOS: uses the same board, menus, and dialogs
  • Windows: uses the same board, menus, and dialogs
3 How to Build

Install Qt6 and CMake on your OS, then follow the same build steps.

  • Qt 6（Widgets, Charts, Network, LinguistTools）
  • A C++17-compatible compiler
  • CMake 3.16 or later
