Show the Menu Panel

Open the menu dock from View in the menu bar

1 Show the Menu Dock

Choose View → Menu in the menu bar to show the menu dock. Menu bar commands are arranged as icon buttons, giving you quick access to frequently used features. The dock first appears as a tab next to the Game Record dock.

Main window: the menu dock shown with View → Menu, next to the Game Record dock

2 Detach the Dock

Drag the menu dock's title bar, or click the float button at the right of the title bar, to use it as a separate window. Place it wherever suits your work. Drag it back to an edge of the main window to dock it again. See Docks for arranging and saving docks.

Menu Tabs

Commands are arranged as buttons in the same tabs as the menu bar

1 File

New, Open…, Save, Save As…, Save Board Image to File…, Save Evaluation Graph Image to File…, and Exit.

File tab

2 Edit

The Copy Game Record formats (KIF, KI2, CSA, USI, JSON, and USEN), the Copy Position formats (SFEN and BOD), Paste Game Record…, SFEN Collection Viewer, Copy Board Image, Copy Eval Graph Image, and Start Position Edit.

End Position Edit, Even Game Setup, Tsume Shogi Setup, Move All Pieces to Piece Box, and Change Turn appear only while you are editing a position.

Edit tab

3 View

Flip Board, Enlarge Board, Shrink Board, Game Appearance…, Show legal moves, Application Font…, Reset Dock Layout, Save Dock Layout…, and Lock Docks.

View tab (Show legal moves is on)

4 Game

Game…, Network Game (CSA)…, Resign, Take Back, Move Now, Abort, Resume, Analyze Game Record…, Cancel Analysis, Mate Search…, Cancel Mate Search, Tsume Position Generator…, Play tsume shogi…, Jishogi Points, and Entering King Declaration.

Game tab (Resign and similar commands are dimmed because no game is in progress)

5 Settings

Engine Settings…, Piece Sound, and Piece Sound Settings…; the interface languages Use System Default, Japanese, English, 简体中文, and 繁體中文; the notation options Follow UI language, Japanese (▲7六歩; ranks 一–九), Western (▲P-7f; ranks a–i), Always show origin in Western notation, and Reading move notation…; and Reset Settings to Defaults…. In the menu bar, the language and notation items are under Language and Move notation and board coordinates.

Choose Reset Settings to Defaults… and confirm to reset all settings, including engine registrations, and close the application. Default settings are used the next time you start it. If you cancel closing at a prompt such as one for an unsaved game record, the settings are not reset. This command is available when no game or analysis is running.

Settings tab

6 Help

Website, Version Info, and About Qt.

Help tab

7 Button States

Clicking a button runs the same command as the matching menu bar item. Buttons for commands that are not available now are dimmed (such as Resign in the Game tab above). Items that can be turned on or off show a ✓ at the top left when they are on (such as Show legal moves in the View tab).

Buttons and Search

Change the button size and filter items by name

1 Buttons at the Top Right

The menu dock has these buttons at the top right.

  • □- / □+: Make buttons and icons smaller or larger.
  • A- / A+: Make button text smaller or larger.
  • Edit favorites: Start adding, removing, and reordering favorites. The button changes to Done editing.

The button and text sizes, the last tab, and your favorites are kept for the next launch.

2 Search Items

Type in Search items in this tab to show only the items whose name or description contains the text. Click the button at the right end of the box to clear it.

The Game tab filtered by “mate”

Favorites

Collect frequently used commands in Favorites for quick access

1 Favorites Tab (Empty)

The ★ Favorites tab shows the items you have added. At first nothing is added, so only a hint is shown.

Favorites tab with nothing added

2 Add Items with Edit Favorites

Click Edit favorites at the top right to start editing; the button changes to Done editing. A green + appears at the top right of each item in every tab. Click it to add the item to Favorites.

Editing favorites: add items with +

3 Remove and Reorder

While editing, the Favorites tab shows a red × at the top right of each added item. Click it to remove the item from Favorites. Drag items to reorder them. Click Done editing when you are finished.

Editing favorites: remove with × and drag to reorder

4 Your Favorites

Added items are collected in the ★ Favorites tab, so you can use frequent commands without switching tabs.

Added items appear in the Favorites tab
