Show the Menu Panel

Open the menu dock from View in the menu bar

1 Show the Menu Dock

Choose View → Menu in the menu bar at the top of the application. The menu dock provides icon buttons for commands, giving you quick access to frequently used features.

Main window: choose View → Menu to show the menu dock

2 Detach the Dock

Drag the menu dock's title bar to detach it as an independent window. Place it anywhere on your desktop to suit your work. Drag it back to an edge of the main window to dock it again.

Menu Tabs

Commands are organized into tabs so you can find them quickly

1 File (F)

Commands for game record files: create, open, save, and save as. You can also export board and evaluation graph images or quit the application.

File tab: create, load, and save game records, or export images

2 Edit (E)

Commands for editing and converting records: copy in KIF, KI2, CSA, USI, SFEN, JSON, or BOD format; paste records; open the position collection viewer; copy board images; start or end position editing; apply initial setups; and change the side to move.

Edit tab: format conversion, copy and paste, and position editing

3 View (I)

Commands for board display: rotate or resize the board, save and load dock layouts, and lock docks.

View tab: board rotation, zoom, and dock layout management

4 Game (G)

Commands for games: start local or CSA network games, resign, take back a move, force an engine move, interrupt play, analyze a record, search for mate, calculate impasse points, and make an entering-king declaration.

Game tab: start games, resign, analyze records, search for mate, and more

5 Settings (S)

Application settings: configure engines and system options, and switch the interface between Japanese and English.

Settings tab: engine settings, system settings, and language selection

6 Help (H)

Help commands: visit the website, read instructions, and view version information or information about Qt.

Help tab: website, instructions, version information, and About Qt

Navigation Buttons

Use the buttons at the top right to adjust sizes and customize the menu

1 Navigation Button Functions

The top-right corner of the menu dock contains these buttons.

  • □- (Smaller Icons): decrease the menu button icon size.
  • □+ (Larger Icons): increase the menu button icon size.
  • A- (Smaller Font): decrease the menu button font size.
  • A+ (Larger Font): increase the menu button font size.
  • ⚙ (Customize): switch to favorites editing mode.

Adjust the icon and font sizes to make the menu comfortable to use.

Navigation buttons: icon size, font size, and customization at the top right

Add Favorites

Add frequently used commands to Favorites for quick access

1 Favorites Tab (Empty)

The ★ Favorites tab displays your saved favorite commands. It is empty until you add some.

Favorites tab: initial state with no saved commands

2 Add Favorites in Customize Mode

Click the gear button (⚙) at the top right to enter favorites editing mode. A green + appears at the top left of each command button in the menu tabs. Click it to add the command to Favorites.

Customize mode: click + to add a favorite

3 Edit and Remove Favorites

Open the Favorites tab while in customize mode to see a red × on saved commands. Click × to remove a favorite. When you are finished, click the gear button (⚙) again to leave customize mode.

Edit favorites: click × to remove an item

4 Favorites Ready

Your saved commands appear together in the ★ Favorites tab, so you can access them quickly without switching tabs.

Favorites ready: saved commands displayed in the Favorites tab
