Prepare a Position

Create a tsume shogi position with the board editor

1 Main Window

Start ShogiBoardQ. Before searching for a tsume shogi solution, prepare the position you want to solve.

Main window immediately after startup

2 Create a Position in the Editor

Choose Edit → Start Position Edit to enter editing mode and create a tsume shogi position. Arrange the pieces freely to set up the position you want.

Position editing: create a tsume shogi position, then click End Edit

3 Confirm the Position

Click End Edit to confirm the position. You are now ready to search for mate.

Position confirmed: the tsume shogi position is ready

Configure Mate Search

Set search options in the mate search dialog

1 Mate Search Dialog

Choose Game → Mate Search to open the dialog. You can configure the following settings.

  • The USI engine to use for the search
  • Thinking time: unlimited or a specified duration
  • The number of candidate moves

Mate search dialog: engine, thinking time, and candidate settings

Search Results

When a mate is found, its solution is displayed

1 View the Mating Line

After the search finishes, the lower panel displays the mating line. Inspect the principal variations for candidate moves to see the sequence leading to mate.

Search results: the mating line displayed in the lower panel

Principal Variations

Replay the mating line one move at a time on a shogi board

1 Principal variation window

Click a principal variation in the search results to open its board window. You can replay the mating line one move at a time.

Principal variation display: starting position (0/3)

2 Replay the Solution

Click Go Forward 1 Move to advance one move at a time and inspect the mating line on the board.

Move 1: Black drops a silver on 1b (1/3)

Move 2: White's king captures on 1b (2/3)

Move 3: Black drops a rook on 2b, checkmate (3/3)
