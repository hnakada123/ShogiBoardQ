基于 Qt6 的跨平台开发

Qt6 框架让 ShogiBoardQ 支持多种操作系统

1 一套源代码支持多种操作系统

ShogiBoardQ 使用 Qt6 和 C++17 开发。借助 Qt6 的跨平台功能，可以用同一套源代码构建 Linux、macOS 和 Windows 版的应用程序。

2 各平台一致的界面

ShogiBoardQ 使用 Qt6 的 Fusion 控件样式，在各平台上提供一致的界面。

  • Linux：支持 KDE Plasma、GNOME 等桌面环境
  • macOS：使用相同的棋盘、菜单和对话框
  • Windows：使用相同的棋盘、菜单和对话框
3 构建方法

在各操作系统上安装 Qt6 和 CMake，然后从包含 Hayanagi 子模块的源代码构建。

  • Qt 6.7 或更高版本（Widgets、Charts、Network、Concurrent、Multimedia、Sql、LinguistTools）
  • 支持 C++17 的编译器
  • CMake 3.16 或更高版本

环境准备、构建命令和发布包，请参阅 Linux、Windows 和 macOS 的构建与发布指南（macOS 为英文）。
