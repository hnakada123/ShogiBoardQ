介面與設定

棋子樣式

除標準棋子外，還有虎紋、戰國漢字、西洋棋風格、字母等，共 40 種。

對局外觀

從樣本中自由組合棋子、棋盤、背景、駒台與對局者資訊。

了解更多 →

應用程式字型

一次變更選單、棋譜、記錄和各對話方塊的字型，可先在預覽中確認。

了解更多 →

停駐面板

自由排列棋譜、思考、評價值圖表等面板，並儲存版面設定。

了解更多 →

選單面板

透過附圖示的選單面板快速執行各項操作，也能把常用功能加入收藏。

走子音效

開啟或關閉走子音效，並調整音量、音高與音色。

了解更多 →

多語言

支援日文、英文、中文（簡體／繁體）介面，可在「設定」→「語言」中切換。

跨平台

以 Qt 6 開發，可在 Linux、macOS 與 Windows 上執行。

了解更多 →

對局

對局

支援人對引擎、引擎對引擎、人對人對局。可設定平手或 13 種讓子、用時、讀秒或每手加時（先後手可分別設定）、最大手數與棋譜自動儲存，引擎連續對局時可每局交換先後手。會判定千日手與連續王手千日手，選取棋子時會標示可移動的位置，中斷的對局可保留局面與剩餘時間繼續進行。

了解更多 →

引擎註冊與設定

選擇 USI 引擎的執行檔進行註冊，並可為每個引擎分別設定雜湊大小、執行緒數、背景思考等選項。

了解更多 →

將棋引擎 Hayanagi

與 ShogiBoardQ 一同開發的 USI 引擎。註冊後即可用於對局、研究與分析，並在詰棋練習中擔任守方。

了解更多 →

CSA 網路對局

連線至 floodgate 等支援 CSA 協定的伺服器，由人或引擎進行網路對局。

了解更多 →

入玉宣言

計算持將棋點數，依 24 點法與 27 點法判定入玉宣言。

了解更多 →

棋譜與局面

棋譜顯示

顯示著法、用時、書籤、註解與變化。棋譜與座標也可切換為西式記法。

了解更多 →

棋譜管理

支援讀取與儲存 KIF、KI2、CSA、JKF、USI、SFEN、USEN，並可透過剪貼簿複製與貼上。局面還能複製為 BOD 格式，貼上時同樣會自動識別。對局者、讓子、用時規則等對局資訊也可編輯並隨棋譜儲存。

了解更多 →

局面編輯

使用駒箱自由擺放棋子，並從編輯好的局面開始對局或研究。

了解更多 →

圖片匯出

將棋盤與評價值圖表儲存或複製為圖片。

了解更多 →

研究與分析

研究模式

讓引擎思考任意局面的候選著法，透過多條主要變化與箭頭進行比較。主要變化可在另一個棋盤（變化棋盤）上逐手重播。

了解更多 →

棋譜分析

以引擎分析整盤棋譜，透過圖表查看每一手的評價值與形勢變化。

了解更多 →

定跡

讀取定跡（開局定式）檔案，顯示、走出並編輯符合目前局面的定跡著法。

了解更多 →

SFEN 局面集檢視器

在棋盤上瀏覽 SFEN 格式的局面集，並將選取的局面匯入主視窗。
