主要特色

從研究、外觀與詰棋三個情境，介紹 ShogiBoardQ 的使用體驗。

研究與分析

候選著法化為箭頭，
形勢變化一目了然

註冊 USI 引擎後，即可在研究模式中分析任意局面，或一次分析整盤棋譜。透過評價值圖表與分析結果列表，能迅速找出形勢轉變的那一手。

  • 候選著法以附編號的箭頭顯示，打入的著法從駒台延伸而出
  • 棋譜分析逐手列出評價值、是否與最佳著法一致以及評價值變化
  • 對局中也能以箭頭查看引擎的最佳著法；引擎對引擎時可同時顯示雙方的思考
  • 透過變化樹、書籤與註解整理研究內容

研究模式 → 棋譜分析 → 對局 →

外觀

40 種棋子，
自由搭配棋盤外觀

透過「檢視」→「對局外觀…」，可從樣本中分別選擇棋子、棋盤、背景、駒台與對局者資訊，並在預覽中確認整體效果。

  • 棋子共 40 種：標準、虎紋、木紋、淺色、深色、戰國漢字、西洋棋風格與字母
  • 棋盤、背景、駒台各 26 種，對局者資訊 20 種，另有 24 種推薦組合
  • 所選外觀也會套用到變化棋盤、詰棋與匯出的圖片

棋子樣式 → 對局外觀 →

詰棋

在棋盤上挑戰
6,000 道詰棋

發行套件收錄 3、5、7、9、11、13 手詰各 1,000 道。從題目列表選題，由內建引擎 Hayanagi 擔任守方，在棋盤上將死對方的玉。

  • 以棋盤卡片瀏覽題目，並依挑戰進度篩選
  • 在剩餘手數內將死即為正解，成立的其他解法同樣判為正確
  • 透過挑戰紀錄與正解手順重播進行復盤
  • 也能以詰棋搜尋與詰棋局面生成器（GUI 與 CLI）自行出題

詰棋練習 → 詰棋局面生成器 → 詰棋搜尋 →

功能一覽

使用指南依用途介紹所有功能的用法。

對局、研究與分析需要註冊支援 USI 協定的將棋引擎。各作業系統的發行套件中都附有將棋引擎 Hayanagi。在此向各位將棋引擎開發者致上謝意。

對局

  • 對局

    支援人對引擎、引擎對引擎、人對人對局。選取棋子時會標示可移動的位置，中斷的對局可保留局面與剩餘時間繼續進行。

  • 引擎註冊與設定

    選擇 USI 引擎的執行檔進行註冊，並可為每個引擎分別設定雜湊大小、執行緒數、背景思考等選項。

  • 將棋引擎 Hayanagi

    與 ShogiBoardQ 一同開發的 USI 引擎。註冊後即可用於對局、研究與分析，並在詰棋練習中擔任守方。

  • CSA 網路對局

    連線至 floodgate 等支援 CSA 協定的伺服器，由人或引擎進行網路對局。

  • 入玉宣言

    計算持將棋點數，依 24 點法與 27 點法判定入玉宣言。

研究與分析

  • 研究模式

    讓引擎思考任意局面的候選著法，透過多條主要變化與箭頭進行比較。

  • 棋譜分析

    以引擎分析整盤棋譜，透過圖表查看每一手的評價值與形勢變化。

  • 定跡

    讀取定跡（開局定式）檔案，顯示、走出並編輯符合目前局面的定跡著法。

  • SFEN 局面集檢視器

    在棋盤上瀏覽 SFEN 格式的局面集，並將選取的局面匯入主視窗。

棋譜與局面

  • 棋譜顯示

    顯示著法、用時、書籤、註解與變化。棋譜與座標也可切換為西式記法。

  • 棋譜管理

    支援讀取與儲存 KIF、KI2、CSA、JKF、USI、SFEN、USEN，並可透過剪貼簿複製與貼上。

  • 局面編輯

    使用駒箱自由擺放棋子，並從編輯好的局面開始對局或研究。

  • 圖片匯出

    將棋盤與評價值圖表儲存或複製為圖片。

詰棋

  • 詰棋練習

    從題目列表選題，在棋盤上解題，並透過挑戰紀錄與正解手順復盤。

  • 詰棋搜尋

    使用 USI 引擎搜尋詰殺，並顯示詰殺手順。

  • 詰棋局面生成器

    在 GUI 或 CLI 中自動產生符合條件的詰棋，檢查餘詰後儲存。

介面與設定

  • 棋子樣式

    除標準棋子外，還有虎紋、戰國漢字、西洋棋風格、字母等，共 40 種。

  • 對局外觀

    從樣本中自由組合棋子、棋盤、背景、駒台與對局者資訊。

  • 停駐面板

    自由排列棋譜、思考、評價值圖表等面板，並儲存版面設定。

  • 選單面板

    透過附圖示的選單面板快速執行各項操作，也能把常用功能加入收藏。

  • 走子音效

    開啟或關閉走子音效，並調整音量、音高與音色。

  • 多語言

    支援日文、英文、中文（簡體／繁體）介面，也可選擇整個介面的字型。

  • 跨平台

    以 Qt 6 開發，可在 Linux、macOS 與 Windows 上執行。

AI 整合

  • AI 用戶端整合（MCP）

    可從 Claude、Cursor、VS Code、Gemini CLI、Codex CLI 等 AI 用戶端要求棋譜轉換、分析、詰棋產生與應用程式操作。

下載

可從 GitHub 發行頁面取得最新版本，免費使用。

  • Windows

    64 位元 Windows（x64）

    1. 下載 ZIP 並全部解壓縮
    2. 執行 ShogiBoardQ.exe
    Windows 版（ZIP）

  • macOS

    搭載 Apple 晶片的 Mac

    1. 解壓縮 ZIP 並開啟 DMG
    2. 將 ShogiBoardQ.app 拖曳到「應用程式」資料夾
    3. 首次啟動遭到阻擋時，請在「系統設定」→「隱私權與安全性」中允許
    macOS 版（ZIP）

  • Linux

    x86_64（AppImage）

    1. 解壓縮 ZIP
    2. 為 ShogiBoardQ-linux-x86_64.AppImage 加上執行權限後執行
    Linux 版（ZIP）

各套件皆附有詰棋題集（6,000 道）與將棋引擎 Hayanagi（含定跡檔案）。系統需求與更新內容請參閱發行說明（日文）。
