# 対局の時間設定と時計表示の動作仕様

更新日：2026年10月10日

## 対象と前提

「対局」ウィンドウから開始する、人間同士・人間対エンジン・エンジン同士の通常対局を対象とする。CSA通信対局の時間管理はサーバーの設定・裁定に従うため、本書の対象外とする。

本書は、2026年10月10日の作業ツリーにある実装を記述する。累積消費時間の表示、人間の初手の計時開始、初手への加算時間の付与に関する修正を含む。

**現在、時間無制限の判定は対局者ごとではなく、先後の時間設定全体に対して行う。** 片方だけ全項目0秒にした場合の挙動は「先後で異なる時間を設定する場合」を参照。

## 設定項目

| 項目 | 意味 |
| --- | --- |
| 持ち時間（時間・分） | 対局者が対局を通して使用する基本の時間。秒へ換算して扱う。 |
| 秒読み（秒） | 基本の持ち時間を使い切った後、各手で使える時間。未使用分は次の手へ繰り越さない。 |
| 1手ごとの加算（秒） | 初手と、以後の各着手確定時に追加される時間。未使用分は残り時間として蓄積する。 |
| 後手／上手に異なる時間を設定 | オフなら左側の設定を双方に適用。オンなら左右の設定をそれぞれに適用する。 |
| 時間切れを負けにする | オンなら使用可能時間を使い切った側を時間切れ負けとする。双方が全項目0秒の場合は時間切れ判定を行わない。 |

秒読みと加算は両者共通の方式として排他である。一方の秒読みに正の値を設定すると、両者の加算が0になる。一方の加算に正の値を設定すると、両者の秒読みが0になる。先手だけ秒読み、後手だけ加算、という併用はできない。

共通設定の場合、無効表示になっている右側の入力値は対局に使わない。

## 時計表示の共通規則

- 盤の横の時計は、各対局者について `HH:MM:SS` 形式で表示する。
- 計時するのは手番側だけ。相手の手番の間はその対局者の時計を進めない。
- 時間制限ありの場合は残り時間を表示する。内部のミリ秒値を秒へ切り上げるため、残り7.2秒は `00:00:08` と表示する。
- 双方が全項目0秒の場合は、それぞれの累積消費時間を表示する。秒未満は切り捨てるため、累積7.2秒は `00:00:07` と表示する。
- 判定・集計はミリ秒で行い、表示値の丸めによって使用可能時間を増減させない。

## 基本の持ち時間だけを設定した場合

基本の持ち時間から、手番中の経過時間を減算する。着手しても時間は追加しない。

例：持ち時間5分、秒読み0秒、加算0秒なら `00:05:00` で開始する。初手を3秒で指すと残りは `00:04:57` となり、次の自分の手番はその残り時間から計時する。

## 秒読みを設定した場合

基本の持ち時間が残っている間は、それを減算する。使い切ると同じ手の途中で秒読みに移行する。切替をまたいだ経過時間も消費する。

秒読みに入った後、期限内に指すと、その対局者の秒読み時間を設定値に戻す。未使用の秒読み時間は蓄積しない。

例：持ち時間0秒、秒読み5秒なら、各手の使用可能時間は5秒。3秒で指しても次の手は5秒となる。

現在の表示実装では、持ち時間0秒の秒読み対局は初期化直後に `00:00:00` を表示し、最初の時計更新で秒読みに移行して残り秒数を表示する。初期表示が0秒でも、設定した秒読み時間は使用できる。

## 加算を設定した場合

開始時に、双方の基本の持ち時間へ初手分の加算時間を足す。以後は、その対局者が期限内に指した時点で次の手の分を加算する。手番が来たときにもう一度加算することはない。

```text
開始時の残り時間 = 基本の持ち時間 + 加算時間
着手確定後の残り時間 = 着手前の残り時間 - 今回の消費時間 + 加算時間
```

| 設定・操作 | 残り時間 |
| --- | --- |
| 持ち時間0秒・加算10秒で開始 | 10秒 |
| 初手を3秒で指す | 10 − 3 + 10 = 17秒 |
| 次の自分の手を5秒で指す | 17 − 5 + 10 = 22秒 |
| 持ち時間5分・加算10秒で開始 | 5分10秒 |

相手が指したことによって自分の残り時間が増えることはない。時間切れ後や終局後の処理で、加算によって時間切れを取り消すこともない。

## 双方が全項目0秒の場合

双方の持ち時間・秒読み・加算がすべて0なら、時間無制限として扱う。

- 双方の時計を `00:00:00` から開始する。
- 自分の手番中は「確定済みの累積消費時間＋現在の手の考慮時間」を表示する。
- 着手確定時に、その手の消費時間を累積へ加える。表示上の二重加算はしない。
- 着手確定後の時計は、その対局者の棋譜欄の総消費時間と一致する。
- 「時間切れを負けにする」がオンでも、対局時計による時間切れ負けは発生しない。
- 時間切れ間近を示す時計の警告色は使用しない。

例：先手が3秒、後手が2秒、先手がさらに5秒考えて指した場合、先手の時計は8秒、後手の時計は2秒になる。両者を合計した10秒をそれぞれの時計に表示するものではない。

秒未満は内部で保持する。例えば同じ対局者が1.7秒、0.7秒使った場合、総消費時間の表示は順に1秒、2秒となる。棋譜の各手の表示秒数は、切り捨てた総消費秒数の前回との差分から算出する。

なお、時間無制限は対局時計の制限がないという意味である。エンジン応答待ちには別途30分の安全上限があり、エンジンが永久に思考し続けることまで保証するものではない。

## 先後で異なる時間を設定する場合

チェックをオンにすると、基本の持ち時間、秒読みの長さ、加算の長さを先後別々に設定できる。ただし、秒読みと加算の排他、および時間無制限の判定は両者共通である。

### 添付画像の設定

| 項目 | 先手／下手 | 後手／上手 |
| --- | --- | --- |
| 持ち時間 | 0時間0分 | 0時間0分 |
| 秒読み | 5秒 | 0秒 |
| 1手ごとの加算 | 0秒 | 0秒 |

現在の実装では、先手の秒読みが正の値なので、対局全体を「時間制限あり」と判定する。

- 先手は1手につき5秒の秒読みで指す。
- 後手の使用可能時間は0秒。後手の時計は累積消費時間の表示には切り替わらない。
- 「時間切れを負けにする」がオンなら、後手の手番で計時が進んだ時点で時間切れになる。
- 同項目がオフなら、対局時計による時間切れ負けにはしないが、後手の時計は残り0秒の表示を続ける。消費時間は棋譜用に集計する。

**「先手は秒読み5秒、後手は時間無制限」という組み合わせは、現在の実装では表現できない。** 全項目0秒を対局者ごとに無制限として扱う仕様へ変更する場合は、時間切れ判定、累積表示、エンジンの思考予算を対局者ごとに切り替える修正が必要になる。本書の作成ではこの挙動を変更していない。

## 計時の開始・中断・終了

- 初手が人間なら、対局開始処理で計時を開始し、相手エンジンの初期化完了を待つために時計を止めない。
- 初手がエンジンなら、エンジン初期化待ちの間は時計を停止し、準備完了後に計時・思考を開始する。エンジン同士では双方の初期化を待つ。
- 累積表示が0秒から1秒へ変わるのは、実際に約1秒を消費した後である。
- 中断中は時計を停止する。再開時には保存した残り時間・考慮時間・累積時間を復元し、初手の加算を再度行わない。
- 「待った」は保存した時計状態へ戻す。
- 終局時は時計を停止し、終局行に記録する消費時間を確定する。以後は秒読みのリセットや加算を行わない。

「時間切れを負けにする」がオフでも、有限の時間設定が無制限表示へ変わるわけではない。残り時間は0で止まり、消費時間の記録は続く。現実装では、加算方式で残り0になった後に指しても加算せず、秒読み方式では着手確定時に秒読みを再設定する。

## エンジンへの時間指定

エンジンには、各対局者の残り時間と、秒読みまたは先後の加算時間を伝える。加算方式では、現在の手で使用できる加算分を含む残り時間を基準とする。

実際に送信する手番側の予算は、通信・探索停止の余裕として最大250ミリ秒を差し引く。このため、表示が10秒でも送信値が9750ミリ秒になる場合がある。対局時計の10秒が減らされたことを意味しない。
