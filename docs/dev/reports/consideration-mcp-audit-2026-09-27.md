# 検討モードのMCP検証（2026-09-27）

`docs/guide/consideration.html` と検討ドックの操作項目を対象に、MCPのstdioクライアントから
実際のShogiBoardQを起動して検証した。通常のユーザー設定と起動済みのアプリは変更せず、
各ケースの設定・棋譜・ソケットを一時ディレクトリに分離した。

## 追加したMCP機能

- `show_dock`: タブ化された検討・思考ドックを表示して前面化。
- `click_widget`: 名前付きの開始・中止・文字サイズなどのボタンを操作。
- `set_widget_value`: エンジン・候補手数・時間・矢印表示などを設定。
- `click_table_cell`: 読み筋テーブルの「盤面」列などをマウスイベントでクリック。
- `get_widget_text`: 選択インデックス・文字サイズ・盤面の候補手矢印も取得。

操作は通常のUIシグナル／マウスイベントを通す。無効な引数、操作不可のウィジェット、
別のモーダル画面で遮られた操作は拒否する。ボタンや値変更は予約後に応答するため、
テストは画面状態を読み取って完了を待つ。

## 修正内容と再現条件

| 再現条件・問題 | 修正 |
|---|---|
| 保存済みのエンジン・時間・候補手数が起動時に初期値へ戻る | エンジン一覧読込と設定復元中の変更シグナルを抑止。候補手変更も直ちに保存 |
| 検討中に候補手数を1から3へ増やしても1候補しか表示されない | 探索の再開時に表示モデル側のMultiPV上限も更新 |
| 時間切れ後の候補手数変更で結果が消え、再開しない | 待機中はstopへの応答を待たず直接再開。再開待ち中の変更は最後の設定に集約 |
| 中止後に矢印表示をオフ・オンすると古い矢印が戻る | 検討終了後は保持した読み筋から矢印を再生成しない |
| 後手の駒打ち矢印の先後判定が現在の読み筋と一致しない可能性 | 各読み筋の基準SFENから手番を判定し、後手の金打ちで検証 |
| 時間設定だけ検討中に変わり、エンジンの制限時間は変わらない | 時間設定を実行中は無効化し、中止後に変更可能にする |
| 中止直後の開始がエンジン終了処理中として無視される | 終了処理が完了してからUIへ終了通知 |
| 起動初期化中の中止でエンジンが破棄され、異常終了する | 初期化中の中止・エラーを保留し、初期化が戻ってから後始末。前回の候補手は初期化前に消去 |
| 登録されたエンジンの実行ファイルが無いと正常な待機状態に戻らない | 起動の成否を伝播し、エラー表示・検討終了処理を実行 |

YaneuraOuでの連続開始・中止による異常終了は、デバッガーでも
`UsiProtocolHandler::initializeEngine` → `errorOccurred` 内の無効な参照として確認した。
読み筋の基準局面も、エンジンへ送ったpositionコマンドから生成するよう統一した。

## 回帰テスト

`mcp/tests/test_consideration.py` は次を検証する。

1. 保存済み設定の復元。
2. 探索中のMultiPV増減。
3. 時間切れ後のMultiPV変更と探索再開。
4. 中止後の矢印再表示防止。
5. 局面移動、経過時間の停止、読み筋盤面の前進・復帰、矢印オン／オフ・回転、文字サイズ、思考ドック。
6. エンジン切替、開始・中止の繰り返し。
7. 検討を開始せず変更した設定の、アプリ再起動後の復元。
8. MCPの不正引数とモーダル画面背後の操作の拒否、エンジン設定画面。
9. 後手の金打ち候補の矢印。
10. エンジン未登録時のエラー復旧。
11. エンジン実行ファイル消失時のエラー復旧。
12. 開始直後、候補手を待たず中止する操作の繰り返し。

実エンジンは同梱Hayanagiと、画面例のYaneuraOu NNUE 9.10git 64ZEN2を使用。
GUIはQtのoffscreen環境で動かし、MCPのスクリーンショットでも表示を確認した。
検証対象は上記の機能・操作順であり、全OS・全エンジン・すべての操作タイミングを網羅するものではない。

再実行例（`SHOGIBOARDQ_TEST_USI_ENGINE` を変更すると別の実エンジンで実行できる）:

```bash
cmake --build build -j 6
ctest --test-dir build --output-on-failure -j 6

env SHOGIBOARDQ_CLI="$PWD/build/shogiboardq-cli" \
    SHOGIBOARDQ_EXECUTABLE="$PWD/build/ShogiBoardQ" \
    SHOGIBOARDQ_TEST_USI_ENGINE="$PWD/build/Hayanagi/hayanagi" \
    python3 -m pytest -q -p no:cacheprovider mcp/tests/test_consideration.py
```
