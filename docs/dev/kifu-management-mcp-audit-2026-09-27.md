# 棋譜管理のMCP検証（2026-09-27）

`docs/guide/kifu-management.html` を対象に、PythonのMCP SDKからstdioサーバーを起動し、
実際のShogiBoardQを操作した。設定・ソケット・保存ファイルは各テストの一時ディレクトリに分離した。
既存のユーザー設定・棋譜は変更していない。

## 追加・改善したMCP機能

- `get_clipboard`: コピーされたテキスト、画像の有無・幅・高さを取得。文字数制限と省略フラグに対応。
- `set_widget_value`: QLineEdit、QPlainTextEdit、QTextEditへのプレーンテキスト入力。
  読み取り専用・パスワード欄・無効な型・モーダルで遮られた操作は拒否する。
- 貼り付けダイアログ・入力欄、棋譜・分岐候補テーブルに操作用のobjectNameを設定。
- 分岐閲覧時の局面・USI手順・総手数・移動可能な上限を、実際に表示している経路に合わせた。
- `get_kifu` の手数上限による省略を `truncated` に正しく反映。

## 再現した不具合と修正

| 再現条件 | 問題と修正 |
|---|---|
| 分岐へ移動して「USI形式でコピー（現在の手まで）」 | 本譜の指し手をコピーしていた。閲覧中の分岐から現在の行までの手順を生成 |
| 投了を含む棋譜の開始局面・途中局面で同コピー | 未来の `resign` が付いていた。終局行まで選択した場合だけ終局コードを追加 |
| 途中局面のSFENを取り込んでSFENコピー | 元のSFEN手数が1へ戻っていた。局面ノードの手数を保持。USI出力でも初期SFENの手数を保持 |
| 対局者名付き棋譜の後にUSI棋譜を読み込む | 前の対局情報・対局者名が残っていた。ヘッダを持たない形式でも対局情報と盤面の名前を更新 |
| 貼り付け時の未保存確認でキャンセル、または不正JSONを取り込む | 入力欄が閉じて入力を失っていた。取り込み成功時だけダイアログを閉じる |
| 情報欠落を警告する保存確認をMCPの `close_dialog` でreject | Cancel以外を承認と扱い保存していた。明示的なOKだけ保存を許可 |

ガイドの「読み込み後に最終局面を表示」は、開始局面へ戻す既存の仕様と異なっていたため、
日本語・英語のガイドを修正した。

## 検証内容

回帰テストは `mcp/tests/test_kifu_management.py` の29ケース。

- 6形式・8拡張子（kif/kifu/ki2/ki2u/csa/jkf/usi/usen）の保存・再読込・上書き拒否と許可。
  Shift_JIS/UTF-8、日本語と空白のあるファイル名、指し手・局面、対応形式のコメント・消費時間・対局者名を確認。
- 6形式のメニューコピーと「クリップボードから貼り付け」による取込。
  KIF/KI2/JKF/USENの分岐保持、USI/CSAの本譜出力を確認。
- 開始・途中・最終局面、分岐、投了前後のコピー。SFEN/BOD取込と盤面画像コピー。
- 実ファイルダイアログでの読み込み・フィルタ選択、拡張子省略、明示拡張子の優先、情報欠落警告の中止。
- SFENファイル読込時の保存先解除、未保存確認のキャンセル／保存中止／破棄、不正入力後の棋譜と入力の保持。
- 貼り付け欄のクリア・空入力・文字サイズ、再起動後の文字サイズ復元、MCPの型検査・読み取り専用欄拒否。
- MCPで人間同士の対局を開始し、1手指して投了、対局終了通知を閉じた後の自動保存と再読込。

実行環境はLinux、Qtのoffscreenプラットフォーム。MCPのスクリーンショットでも盤面と棋譜欄を確認した。
OSネイティブのファイルダイアログや他アプリとのシステムクリップボード共有、全OSの動作を網羅する検証ではない。

## 再実行

```bash
cmake --build build -j 6
ctest --test-dir build --output-on-failure -j 6

env SHOGIBOARDQ_CLI="$PWD/build/shogiboardq-cli" \
    SHOGIBOARDQ_EXECUTABLE="$PWD/build/ShogiBoardQ" \
    python3 -m pytest -q -p no:cacheprovider mcp/tests/test_kifu_management.py
```

各ケースは一時ディレクトリにMCPの要求・応答を `mcp.jsonl` として保存する。

`build/kifu-mcp-audit/` に保存した（ローカル生成物）。
