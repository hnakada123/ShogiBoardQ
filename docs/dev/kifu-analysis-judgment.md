# 棋譜解析の形勢判断基準

## 概要

棋譜解析の形勢判断は `src/analysis/kifuanalysislistmodel.cpp` の `getJudgementString()` 関数で実装されている。評価値（先手視点、centipawn単位）の絶対値をもとに形勢を5段階で判定する。

## 判断基準

| 評価値の絶対値 | 形勢表現 | 表示例 |
|---|---|---|
| 0〜100 | 互角 | 互角 |
| 101〜300 | やや有利 | 先手：やや有利 / 後手：やや有利 |
| 301〜600 | 有利 | 先手：有利 / 後手：有利 |
| 601〜1000 | 優勢 | 先手：優勢 / 後手：優勢 |
| 1001以上 | 勝勢 | 先手：勝勢 / 後手：勝勢 |

- 評価値は先手視点（正=先手有利、負=後手有利）。後手番の局面ではエンジンの評価値の符号を反転して記録する（`AnalysisResultHandler::commitPendingResult()`）
- 「互角」の場合は先手/後手の接頭辞なし
- それ以外は評価値の符号に応じて「先手」または「後手」を付け、`tr("%1：%2")` で「先手：優勢」のように表示する
- 評価値が「-」（定跡・評価値なし）のときは空欄

## 詰みの場合

評価値に「詰」または「mate」が含まれる場合は、上記の閾値判定ではなく以下のように表示する。詰みの手数も先手視点に変換済みで、`mate 0` は先手番の局面で先手が詰んでいることを表す（後手番の局面で後手が詰んでいる場合は `mate +0` になる）。

| 条件 | 表示 |
|---|---|
| 負の値（`mate -3`・`mate -` など）または `mate 0` | 後手勝ち |
| 上記以外（`mate 5`・`mate +`・`mate +0` など） | 先手勝ち |

## 実装箇所

- **関数**: `getJudgementString()` (`src/analysis/kifuanalysislistmodel.cpp`)
- **表示**: `KifuAnalysisListModel::data()` のカラム4（「形勢」列）で呼び出される
- **テスト**: `tests/tst_analysis_coordinator.cpp` の `mateJudgement`
