# 止めたワークフロー

通常版（ShogiBoardQ）から引き継いだワークフローのうち、実験版（ShogiBoardQ-P2P）で動かさないものを置く
（開発方針 5章）。`.github/workflows/` の外にあるので、GitHub Actions は実行しない。

| ファイル | 止めた理由 |
|---|---|
| `release.yml` | タグの push と手動実行で動き、macOS・Windows の署名用 Secrets を参照し、Release へ書き込む。実験版の配布（D5）は、専用のジョブと最小限の資格情報で作り直す |
| `maintenance-reminder.yml` | 月次のスケジュールで Issue を作る。実験版の保守の手順を決めるまで動かさない |

参考のために残している。実験版の配布を始めるときは、これをそのまま戻さず、開発方針 5.1節の
配布の段階の項目（SBOM・来歴の証明・通信プロセスの署名）を満たすように作り直す。
